description: Sync live IBKR positions into this repo (snapshot section + holdings.md)
---

Follow the [IBKR Positions Sync](../../portfolio/sync-sop.md#ibkr-positions-sync) procedure in the [Portfolio Sync SOP](../../portfolio/sync-sop.md).

1. Fetch positions via `get_account_positions` (Interactive Brokers MCP, account U19421206) and dump the raw result to JSON — no standalone script can call this MCP tool (see [scripts/TOKEN-OPTIMIZATION-PLAN.md](../../scripts/TOKEN-OPTIMIZATION-PLAN.md) finding #1).
2. Resolve tickers via the live ticker-lookup CSV (`https://www.interactivebrokers.com/download/fracshare_stk.csv`), falling back to [`portfolio/reference/ibkr-ticker-lookup.csv`](../../portfolio/reference/ibkr-ticker-lookup.csv) if unreachable — see the SOP for the exact fallback procedure.
3. Run `python -m scripts.sync_ibkr --positions <positions.json> --balances <a JSON file shaped {"currencies": {...}}, giving the live exchange_rate per non-USD currency held — from ibkr.md's most recent /sync-balances data> --holdings portfolio/holdings.md --total-value <Net Liquidation Value currently in ibkr.md>` to compute the positions table, Gross Position Value, Unrealized P&L, and the per-ticker Weight % patch to `holdings.md` in one call, instead of hand-deriving the math/table. Paste its positions markdown fragment into [`portfolio/snapshots/ibkr.md`](../../portfolio/snapshots/ibkr.md) (update the positions table and position-derived header fields — Gross Position Value, Unrealized P&L, "Positions last synced" — leaving the Cash Balances table and cash-derived header fields untouched) and apply its patched `holdings.md` output. Note the Net Liquidation Value's date if it isn't from today. If it exits with `MissingInputError` (e.g. a currency with no `exchange_rate`), stop and ask rather than assuming an FX rate.
4. The script's `patch_holdings_weights` only rewrites the Weight % cell for tickers it finds already present in `holdings.md`'s rows — it never invents a new row (a new position belongs to `/new-position`, not a sync); if it reports a ticker `not_found`, flag it rather than silently dropping it.
5. Push to a `claude/`-prefixed branch: stage `ibkr.md`, `holdings.md`, and the lookup CSV if refreshed, commit with the message `Sync IBKR positions — YYYY-MM-DD`, open a PR with that same title, and enable auto-merge (squash) on it — if that reports the PR already clean/mergeable with nothing pending, merge it directly (squash) instead (see sync-sop.md).
