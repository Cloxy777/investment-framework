description: Sync live IBKR cash balances into this repo (snapshot section + holdings.md)
---

Follow the [IBKR Cash Balances Sync](../../portfolio/sync-sop.md#ibkr-cash-balances-sync) procedure in the [Portfolio Sync SOP](../../portfolio/sync-sop.md).

1. Fetch cash balances via `get_account_balances` (Interactive Brokers MCP, account U19421206) — per-currency cash/settled cash/net liquidation/FX rate, plus the consolidated `BASE` row — and dump the raw result to JSON (`{"base": {...}, "currencies": {...}}`; no standalone script can call this MCP tool). Use the live `exchange_rate` for any FX conversion — never assume or look up a rate elsewhere.
2. Run `python -m scripts.sync_ibkr --balances <balances.json>` to compute the Cash Balances table, Net Liquidation, and Total Cash — including recomputing any non-USD position's USD-equivalent (e.g. XEON) from the live FX rate — in one call. Paste its cash markdown fragment into [`portfolio/snapshots/ibkr.md`](../../portfolio/snapshots/ibkr.md) (update the Cash Balances table and cash-derived header fields — Net Liquidation, Total Cash, "Cash balances last synced" — leaving the positions table and position-derived header fields untouched). If it exits with `MissingInputError`, stop and ask rather than assuming a missing balance/rate.
3. Refresh [`holdings.md`](../../portfolio/holdings.md): the `CASH (IBKR)` row, and — since Net Liquidation Value (the shared weight-% denominator) just changed — re-run `python -m scripts.sync_ibkr --positions <positions.json from the most recent /sync-positions run> --balances <balances.json> --holdings portfolio/holdings.md --total-value <the refreshed Net Liquidation Value>` to recompute weight % for every row and apply the patch, using position market values from the most recent `/sync-positions` run — note its date if it isn't from today.
4. Push to a `claude/`-prefixed branch: stage `ibkr.md` and `holdings.md`, commit with the message `Sync IBKR cash balances — YYYY-MM-DD`, open a PR with that same title, and enable auto-merge (squash) on it — if that reports the PR already clean/mergeable with nothing pending, merge it directly (squash) instead (see sync-sop.md).
