# Glossary (site terms, UA -> EN)

| UA term | EN meaning (as used on the site) |
|---|---|
| Матриця | The 5×5 grid of quality level (A–E) × price word that maps to a verdict |
| Рушій | "The engine": the automatic rules that compute every card from data |
| Картка | Company card (`/t/<TICKER>/`) |
| Вердикт | Final recommendation label (STRONG BUY, BUY, BUY WAIT, AVOID, ЛИШЕ СПЕКУЛЯЦІЯ, НЕ МІЙ СЕКТОР, БРАКУЄ ДАНИХ) |
| Слово ціни | "Price word": дешево / справедлива / дорого, але росте / дорого без росту / пастка дешевизни / немає мультиплікатора |
| Рівень (A–E) | Quality level from the 0–100 quality score, after caps |
| Бал | Score (points); plural "бала/балів" |
| Ворота 0/1/2/3 | Gates: 0 competence circle, 1 quality level, 2 price (lenses), 3 basis-related re-check (basis switcher recomputes gates 2 and 3) |
| Коло компетенції | Circle of competence: is the business in a basket Taras understands |
| Кошик | Basket: sector/business-model bucket from the registry (good, neutral, stop-list, speculation-only) |
| Стоп-лист | Stop-list baskets -> НЕ МІЙ СЕКТОР |
| НЕ МІЙ СЕКТОР | "Not my sector": analysed fully, verdict blocked by stop-list; shadow verdict shown |
| ЛИШЕ СПЕКУЛЯЦІЯ | Speculation only (position ≤ 1% tracking size) |
| БРАКУЄ ДАНИХ | Not enough data for a verdict |
| BUY WAIT | Want to buy but not now (price/flag/arithmetic); card names an entry price |
| Лінзи (ціни) | The 5 price lenses each −2…+2: vs S&P 500, vs own history, PEG, FCF yield after SBC, growth vs market |
| Базис | Valuation basis: NTM P/E, P/OCF, P/FCF, P/FFO |
| NTM | Next twelve months (forward) |
| TTM / LTM | Trailing / last twelve months |
| PEG | P/E divided by EPS growth |
| FCF, OCF | Free cash flow, operating cash flow |
| SBC | Stock-based compensation ("опціони") |
| EPS | Earnings per share |
| CAGR | Compound annual growth rate; "базовий CAGR" = base scenario 5-year return with no multiple expansion |
| Арифметика х2 | 5-year doubling arithmetic: does base scenario deliver ≥ the BUY bar (14–15% p.a.) |
| Ред флаги / прапорці | Red flags: critical (cap C, no BUY, −8 pts), serious (−4), minor (0) |
| Відомі ризики | Known risks: measured but below-flag risks; informational |
| Ознаки | "Ten signs of a good company" checklist |
| Стеля (рівня) | Level cap: reason the displayed level is below what the score would give |
| Гістерезис | Sticky thresholds: leave a state only after crossing by margin |
| Зона BUY | All companies with verdict BUY or STRONG BUY |
| Переглянуто / переглянув | Reviewed by Taras (manual review), needed for STRONG BUY |
| Оцінка Тараса | Taras's own separate rating, not part of the engine |
| Вочліст | Watchlist (max 20 tickers, browser-stored) |
| Кабінет | "Cabinet": account menu |
| Клуб | Taras's paid community; members get access without extra payment |
| Просадка | Drawdown from max |
| Добірки | Preset collections (screener filters) |
| Кіл-лайни | Kill-lines: conditions that break the thesis (watch at next report) |
| Тіньовий вердикт | Shadow verdict shown beside НЕ МІЙ СЕКТОР |
| Закрите тестування | Closed beta |
