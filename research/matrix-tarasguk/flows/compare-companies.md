# Flow: compare 2–4 companies

1. `/compare/` (or card button "порівняти з …" -> `/compare/#TICKER/`).
2. Click field "додати компанію", type ticker/name, pick suggestion -> chip `TICKER · Name ×`. Repeat (min 2, max 4).
3. Result table appears in columns: verdict block (verdict, price word, "what must change for next verdict"), level+score, 8 components, valuation lens data, ten signs, flags, x2 arithmetic, Taras's rating, price-indexed chart. Better value highlighted green.
4. Remove with ×; URL hash `#GOOG/META` reflects the set (shareable).
