# x2 arithmetic (5-year scenarios) — recovered formulas

Reference code: `engine_replica.py` (`growth_path`, `x2_full`, `x2_check`, `x2_values_check`). Evidence: 20 cards; CAGR error vs displayed <= 0.2 pp for all three scenarios on 20/20 cards; scenario multiples exact (<= 0.16 rounding). Card text itself documents the method ("Як рахуємо ріст на 5 років (CAGR)…"); this file records the numbers behind it.

## 1. Inputs
- `p0` current price (USD; non-US uses the "у рушії" USD price), `EPS0` = NTM EPS (same as in NTM P/E; built from 4 quarterly consensus forecasts), `D` = consensus data date (03.10.2026).
- FY consensus table (card block "Що думають аналітики"): per fiscal year end date, EPS, analyst count (FMP). Last FY in the table is the "farthest year".
- Business-type decay rule (printed in the card: "правило рушія: …, темп затухання d, довгостроковий ріст L"): **predictable** (types platform, payments_network, subscription): d=0.95, L=5 %; **cyclical** (manufacturer): d=0.85, L=4 %; **all others** (software, cloud_hyperscaler, semis_monopoly, retail_membership, advertising, …): d=0.90, L=4 %.

## 2. 12-month segments and the five growth steps — Fitted (step 1-2 within 0.1-0.6 pp, steps 3-5 within 0.1 pp)
Segment k = [D + (k-1) years, D + k years). `seg_k = sum over fiscal years FY overlapping the segment of EPS_FY x round(overlap_days / FY_days x 12) / 12` (**whole-month weights**; a day-count weighting fits worse: ABNB step1 18.9 % needs months).
`cons_j = seg_{j+1} / seg_j - 1` (j = 1..5). Which source gives step j (printed legend "консенсус (у дужках кількість) / наш прогноз із затуханням"):
- j = 1: always consensus.
- j >= 2 and the two segments touch only years that are not the farthest FY: analyst count n = min count over the touched years; **n >= 10 -> consensus**; **3 <= n < 10 -> min(our, (our + consensus)/2)**; n < 3 or the farthest year touched -> **our**.
- `our_j = min(25 %, prev x f)` with `f = 0.75 if prev > 20 % else d` (prev = previous step, whatever its source). The 25 % cap applies only to our model (consensus steps like ORCL 35.1 % are not capped). The "x 0.75 when previous > 20 %" fast-fade is inferred from 10 cards (META 23.1 -> 17.4, NVDA 21.6 -> 16.3, MSFT 22.4 -> 16.9, TSM 20.0 -> 18.0 [not > 20 -> normal 0.9]).
Residuals: step 1 off by 0.6 pp on AMD, NVDA (FY ends Jan/Dec with large steps) — unexplained (probably rounded FY EPS displayed vs full precision used by the engine).
TSM (20-F filer): FY table not shown on the card; displayed path used.

## 3. Scenarios — Exact
```
EPS5_base = EPS0 x prod_{i=1..5}(1 + g_i)
EPS5_pess = EPS0 x prod(1 + 0.5 g_i)          # coefficient 0.50 on ALL five steps ("коефіцієнт 0,50 з наших налаштувань")
EPS5_opt  = EPS5_base                          # same path
M_base = min(NTM_PE, mean3_trailing_PE x NTM_PE / trailing_PE)   # 3y average trailing multiple rescaled to NTM basis; if no history: NTM_PE
M_pess = min(16, M_base)                       # "песимістичний мультиплікатор 16"
M_opt  = M_base x 1.2 if M_base > 20.1 else 20.1               # Fitted on 19 cards (20.1 = S&P forward P/E; the card says "повернення до середнього за 3 роки або стеля з наших налаштувань")
price5 = EPS5 x M ;  CAGR = (price5 / p0)^(1/5) - 1
```
Checks: ABNB base multiple 29.3 x 26.3/36.0 = 21.4 (card 21.4); opt 21.4 x 1.2 = 25.7 (card 25.7); ADBE (base 8.8 < 20.1) opt 20.1; NVDA (19.5 < 20.1) opt 20.1; AVGO (20.4 > 20.1) opt 24.5.

## 4. Bars and price table — Exact
Bars: BUY bar **15 %** (level A: 14 %; V (A) printed "при базовому CAGR вище 14 %"), HOLD lower bound **10 %** (settings). Table "За якою ціною буде 15 % на рік": `BuyPrice(t) = price5_base / (1 + t)^5` for t = 15 % ("ціль") and 10 % ("нижня межа HOLD"); the "до поточної" column is `BuyPrice/p0 - 1`. Chart "Арифметика х2: три сценарії" also lists the 5-year price at exactly 15 % and 10 %: `p0 x 1.15^5` and `p0 x 1.10^5` (ABNB $327 / $262). ABNB check: 308.24/1.15^5 = 153.25, /1.10^5 = 191.39.
"Що закладено в ціну": required EPS growth `g_req(r) = (1 + r) x (p0 / (EPS0 x M_exit))^(1/5) - 1` where `M_exit = M_base`, r = 15 % (BUY) or 10 % (market) -> ABNB 19.9 % and 14.6 % (card 19.9 / 14.6); the card also prints "консенсус на 2 р." (annual consensus growth of FY+2, ABNB 19.4 %, analyst count) and "наш прогноз за шляхом рушія" = geometric mean of the five base steps, `(EPS5/EPS0)^(1/5) - 1` (ABNB 18.5 %, verified).

## 5. Verdict effects — Exact
`base CAGR < 10 %` -> BUY/STRONG BUY become BUY WAIT; `10 % <= CAGR < bar` -> STRONG BUY becomes BUY; STRONG BUY also needs `pessimistic CAGR >= 0`. (ADBE base 14.6 < 15: capped at BUY anyway because not reviewed.)

## 6. Unknown
- "х2 досягається у році N" (year the price doubles): printed for each scenario ("не досягається" or "у році 4,0"). My path-simulations (linear/geometric multiple interpolation, constant multiple, crossing interpolation) do not reproduce it (22/27 off by 0.1-0.6 years; e.g. AMD base shows 2.4, simulation 1.8). Not Exact. Cards that never double show "не досягається" when 5y CAGR < ~14.9 % (consistent with 2^(1/5)).
- Source of the 1-quarter NTM EPS (`EPS0`, quarterly consensus) is taken as displayed.

# UPDATE 2026-10-03 (paid tier, 487 cards): fit by FY-table size
Base-scenario CAGR within 0.3 pp of the card: **FY table >= 4 fiscal years: 248/288 (86 %)**; 3 years: 42/130 (32 %); 2 years: 2/21; 1 year: 0/1; 10 cards raise exceptions (no EPS table / no multiple). Pessimistic and optimistic follow the base closely (341/456 and 307/456 within 0.3 pp overall).
- Decay-rule table by registry business type (printed on every card: `правило рушія: <class>, темп затухання d, довгостроковий ріст L %`): **predictable** (platform, payments_network, subscription, data_monopoly): d 0.95, L 5 %; **cyclical** (manufacturer, cyclical, commodity): d 0.85, L 4 %; **rest** (advertising, bank, cloud_hyperscaler, consumer_brand, heavy_machinery, other, pharma, reit, restaurant, retail, retail_membership, semis_monopoly, software): d 0.90, L 4 %.
- **Why short tables fail**: when the printed FY table has 3 or fewer years the engine's step 1 uses a fiscal year beyond the printed table (FMP returns FY+3 estimates with only 1-2 analysts that the card does not print because "<3 analysts"). Step 1 shown ≈ the last printed FY growth (median error 0.8 pp) but not reproducible from the card. Extrapolating the last FY with last growth (implemented) gets 32 %.
- Cases with anomalies: currency mismatch between FY EPS and price (CSU shows -22 % growth), non-consecutive FY rows (ADM table shows FY2025 and FY2027 only), first fiscal year already past the data date (FFIV/AAPL-type Sept FY ends: handled).
- "х2 досягається у році N": still not reproduced.
