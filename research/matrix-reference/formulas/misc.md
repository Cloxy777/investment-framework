## Screener URL-hash grammar — Exact
`#key=value&key=value`, multi values comma separated (`ціна=FAIR,CHEAP`), order independent. Keys: `verdict` (STRONG_BUY,BUY,BUY_WAIT,AVOID,SPEC_ONLY,NEED_DATA,NOT_MINE), `level` (A..E), `price` or Ukrainian `ціна` (CHEAP,FAIR,EXPENSIVE_GROWING,EXPENSIVE_NO_GROWTH,VALUE_TRAP,NO_MULTIPLE), `quadrant` (cheaper_on_business, cheaper_on_estimates, pricier_on_business, pricier_without_reason), `sector` (basket key), `subsector` (key e.g. `cars`), `review` (reviewed/partial/engine), `basis` (pe, pocf, pfcf, pffo), `risks` (yes/no), `cap` (review, flags, debt, moat), `newbuy`=1, `index` (nasdaq100, sp500), `own`=1, `crit`=1, `matrix` (cell / gate0 / changed), numeric `cagr_min`, `peg_max`, `yield_min`, `dd_min`, text `like`, sort `sort=<col>&dir=1|-1`. Raw capture: `data/lists/screener-hash-keys.txt`.
Numeric filter behaviour (`data/lists/screener-probes.txt`): non-numeric input is ignored for `cagr_min`, `yield_min`, `dd_min` but makes `peg_max` return 0 rows; `peg_max` <= 0 returns 0 rows (only positive PEG qualifies); decimal comma accepted ("5,5"); `1e2` parsed as 100; negative thresholds accepted (no validation error); space input -> hash `=+`; `like` is a ticker substring match (digits give 0).
Sorting: first click best->worst (`dir=1`), second reverse; default `sort=score&dir=1`.

## Data layer facts
- Prices: FMP daily close (card chart: daily points, table `Дата | Ціна закриття | Від початку періоду | S&P 500 (за SPY) від початку періоду`; periods 1 міс., 6 міс., YTD, 1 рік, 5 років, Макс; SPY used as S&P proxy; fund fee ~0.1 %/yr).
- Fundamentals: SEC EDGAR XBRL companyfacts (quarterly, 20 quarters), FMP statements for gaps ("FMP: звітність компанії"), IFRS tags for 20-F filers (TSM: `ifrs-full:ProfitLossAttributableToOwnersOfParent`).
- Consensus: FMP annual estimates by FY with analyst counts; quarterly consensus summed for NTM; no FCF/OCF forecasts ("FMP не дає прогнозу FCF або OCF"); no guidance.
- Histories accumulate nightly since 14-19.09.2026 (level history days 12-15; quadrant needs 63 snapshots, forward P/E history needs 365).
- AI drafts: guidance changes and one-off items from press releases/notes are produced by an AI draft step with a confidence label and shown only as notes ("чернетка ШІ, впевненість high/medium"); they do not enter the verdict except through the one-off exclusion rule.
